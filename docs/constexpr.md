# C++ `constexpr` 使用说明

## 基本用法
- 用于变量：声明常量表达式，且尽量在编译期求值。
- 用于函数：允许在编译期求值（若实参为常量表达式），也可在运行期调用。
- 用于构造函数/成员函数：使对象在编译期可构造（需满足常量表达式约束）。

示例：
```cpp
constexpr int kSize = 64;

constexpr int square(int x) {
    return x * x;
}

constexpr int kArea = square(8); // 编译期求值
int runtime = square(3);         // 运行期调用同样可用
```

## 典型适用场景
1. **需要编译期常量的场合**  
   例如数组大小、枚举/模板参数、`switch` 的 `case` 常量等。
2. **性能敏感、可提前计算的逻辑**  
   把可确定的计算放到编译期，减少运行期开销。
3. **确保不可变性与表达意图**  
   表达“此值/函数可以在编译期确定”，提升可读性与安全性。
4. **元编程与类型计算**  
   与模板、`constexpr if` 等组合，做静态分支或编译期配置。

## 注意事项
- `constexpr` 变量会隐式成为 `const`，但 `const` 变量不一定是常量表达式。
- `constexpr` 函数需满足常量表达式的限制（如不能包含运行期才可确定的副作用）。
